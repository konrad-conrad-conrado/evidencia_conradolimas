# Sistema de Gestión de Citas

Este proyecto simula un **sistema de administración de citas** para un consultorio médico. Permite registrar doctores y pacientes, crear y relacionar citas, controlar el acceso mediante administradores y almacenar información en archivos (CSV, o alternativamente JSON/XML). El sistema está diseñado para ser **portable** y ejecutarse en cualquier sistema operativo con Java, compilándose como un **FAT JAR** (todas las dependencias incluidas).
